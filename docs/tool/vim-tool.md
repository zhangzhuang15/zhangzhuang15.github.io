# vim

## 从开始位置往后搜索关键字

`/` + 你要搜索的关键字，然后按下回车激活查询，继续按 n 查询下一个，按 N 查询上一个。

## 从末尾位置往前搜索关键字

`?` + 你要搜索的关键字，然后按下回车激活查询，继续按 n 查询下一个，按 N 查询上一个。

## 匹配的关键词高亮

当使用搜索关键词，发现匹配的关键词并没有高亮，只是在关键词的前方出现光标，这个光标很不醒目，影响查看，你可以尝试下面的操作，让匹配的关键词高亮。

按下`esc`，输入`:set hlsearch`。

## 关键词高亮颜色调整

尽管搜索的关键词高亮了，但是每个操作系统中预设的高亮前景色和背景色存在差异，造成高亮状态下，关键词无法看清的状况。比如你本地的 vim 看得很清楚，通过 ssh 登录到远程服务器后，服务器的 vim 就看不清高亮文字了。那么，我们可以采用下面的方法设置前景色和背景色。

按下`esc`，输入`:highlight Search ctermfg=black ctermbg=lightblue`

## vim 主题颜色切换

默认情况，vim 的主题颜色是前景色为白色，背景色为黑色，你也可以切换到另一种风格。

按下`esc`，输入`:colorscheme blue`, 这样就切换到 blue 主题，你也可以尝试输入别的颜色词，感受差别。
